# Golden Set v3 扩充与验收报告

## 结果摘要

Golden Set 已从 70 条扩充到 150 条，新增 80 条受控合成案例。新增数据包含
40 条盲测案例和 30 条带本地图片资产的多模态案例。数据契约、配额审计、
资产哈希和拆分互斥检查均已通过。

均已满足。

## 盲测隔离

- `golden_set_v3_tuning.csv`：110 条开发与回归案例。
- `blind_set_v1.csv`：40 条盲测案例，20 条通过、20 条拒绝。
- 两个文件的案例 ID 完全互斥，合集等于完整 150 条数据。
- `split_manifest.json` 固定三个文件的计数与 SHA-256。

盲测文件当前位于同一工作区，属于流程隔离而非权限隔离。正式团队使用时应将
盲测文件迁移到只有数据管理员和评测流水线可访问的位置。

## 多模态资产

30 个 PNG 资产由固定脚本生成，分别覆盖商品、视频、查询、店铺名和店铺头像。
每个资产包含可见文本证据与对应视觉结构，不包含生产数据。资产清单记录路径、
媒体类型、来源和 SHA-256，数据验证器会检查缺失文件、错绑和内容变化。

这些资产属于受控 OCR 与布局测试，不代表自然商品照片分布。真实图片、遮挡、
低清晰度和复杂背景仍需在后续数据批次中补充。

## 规则基准

运行：`EV-DAY6-RULES-V3`

| 指标 | 结果 |
| --- | ---: |
| 自动判定准确率 | 100.0% |
| 覆盖率 | 63.3% |
| 分流准确率 | 80.0% |
| 误放率 | 0.0% |
| 误拒率 | 0.0% |
| 政策准确率 | 100.0% |

规则引擎无法读取图片，因此主动将 30 条多模态案例转人工。自动判定准确率和
安全错误率保持稳定，但覆盖率与分流准确率未达到通用门禁。这是预期的能力差距，
不能通过把图片 OCR 文本复制到输入字段来规避。

后续 `rules-ocr` 基准通过 macOS Vision 在运行时读取图片证据，将覆盖率提升到
81.3%、分流准确率提升到 98.0%，自动判定准确率和政策准确率均为 100%，
误放率与误拒率均为 0%。3 条仅声明无品牌的图片负向对照仍保持人工复核。

## 标注状态

新增 80 条案例已完成结构、政策、配额和一致性自动检查，标注台账状态为
`synthetic_verified`。该状态不等同于独立人工复核。用于生产发布判断之前，
仍需两名独立标注人员复核，并对不一致案例执行仲裁。

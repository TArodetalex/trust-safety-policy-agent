# Day 6 生产路由策略

## 目标

在不降低 Day 5 安全指标的前提下，将文本规则、本地 OCR、多模态 LLM 和人工
复核组合为可审计、可降级的生产判定链路。

## 路由顺序

| 输入 | 第一阶段 | 升级条件 | 终止路由 |
| --- | --- | --- | --- |
| 纯文本 | Rules | 不升级模型 | 自动判定或人工复核 |
| 本地图片 | Rules + OCR | OCR 未决或低于阈值 | LLM 或人工复核 |
| 远程图片 | Multimodal LLM | 模型不可用或未决 | 人工复核 |
| 输入冲突/损坏 | Route Guard | 不升级 | 人工复核 |

纯文本冲突不会升级 LLM。规则已经能识别冲突信号，此时引入概率模型只会增加
成本和判定波动，不能补齐缺失事实。

## 自动化门槛

门槛由 `config/production_routing_v1.json` 固定：

- 文本规则置信度至少为 0.85。
- OCR 产生的规则决策置信度至少为 0.85。
- LLM 决策置信度至少为 0.85。
- 图片自动通过必须引用正向政策或豁免证据。
- LLM 图片通过必须由本地规则从视觉观察中重新命中具体豁免。
- 图片自动拒绝必须包含匹配的政策标签和政策证据。
- `need_review`、低置信度、无证据、无模型、请求失败和图片读取失败均转人工。

LLM 输出还需通过 `LLMPolicyAdjudicator` 的本地结构校验、政策标签校验和
chunk ID 校验。模型不能自行发明政策依据。

## 故障与降级

1. OCR 不可用时，本地图片可升级到已配置的 LLM。
2. LLM 未配置、超时、返回非法 JSON 或证据无效时转人工。
3. 同时提供本地路径和远程 URL 时拒绝自动处理。
4. 不使用“图片中未识别到违规文本”作为自动通过依据。
5. 不读取 Golden Set 真值、预期路由或标签参与生产决策。

## 可观测性

每次生产评测额外写出 `routing_records.jsonl`，记录：

- 实际选中的引擎；
- 是否发生升级；
- 每个阶段的结果、置信度、接受状态和原因；
- 最终标准化决策。

评测报告同时按 development、regression、blind 切分输出指标。发布判断必须
检查 blind 切片，不能只看总体指标。

## 发布门禁

沿用 `evaluation_gates_v1.json`：

- 自动判定准确率不低于 95%；
- 分流准确率不低于 90%；
- 总体覆盖率不低于 80%；
- 误放率不高于 2%；
- 误拒率不高于 2%。

生产候选还要求 blind 切片无误放、无误拒。若 LLM 提升覆盖率但破坏上述安全
指标，不进入主路由，可保留为 shadow 流量观察。

## 覆盖率修复续期

Golden Set v3 完成后，纯规则基准因主动回避 30 条图片案例，覆盖率为 63.3%，
低于 80% 门禁。文本自动判定准确率为 100%，缺口完全来自多模态能力，而不是
文本规则召回。

新增 `rules-ocr` 混合引擎后，本地图片先由 macOS Vision OCR 读取，再交给同一
政策规则和证据校验。自动化范围限制如下：

- 明确违规信号且有对应政策证据时自动拒绝。
- 明确命中兼容、二手、普通词义、背景曝光或联名豁免时自动通过。
- OCR 失败、低置信度、远程图片、冲突信号或只声明“无 Logo”时转人工。
- 不读取 Golden Set 标签、标注台账或资产清单中的真值字段。

最终冻结基准为 `EV-DAY5-RULES-OCR-V1`：

| 指标 | 纯规则 | Rules + OCR |
| --- | ---: | ---: |

| 自动判定准确率 | 100.0% | 100.0% |
| 分流准确率 | 80.0% | 98.0% |
| 政策准确率 | 100.0% | 100.0% |
| 误放率 | 0.0% | 0.0% |
| 误拒率 | 0.0% | 0.0% |

剩余 3 条图片负向对照继续转人工，未通过“没有识别到违规文本”推导自动通过。
